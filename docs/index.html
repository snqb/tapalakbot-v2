Как это работает

Технологии, которые делают TapalakBot быстрым и умным.

🧠 DeepSeek LLM

DeepSeek-v4-pro — 10x дешевле Claude, адекватный русский язык, поддержка function calling. Генерирует поисковые запросы, анализирует результаты, формирует ответы.

;; Model config
{:deepseek-v4 {:provider :deepseek
              :model "deepseek-v4-pro"}}

🔍 Smart Search

Один инструмент для всех покупательских запросов. LLM генерирует 4-6 оптимальных запросов, выполняет параллельный поиск, возвращает отфильтрованные результаты.

;; Pipeline: intent → queries → search → curate
smart_search("iPhone 13 до 30000")
→ ["iPhone 13", "айфон 13", "Apple iPhone"]
→ 40+ results → top 5

⚡ Progressive Streaming

Пользователь видит текст в реальном времени. Debounce 1500ms, phase tracking, status callbacks. Никакого «думаю...» — сразу показываем прогресс.

;; Stream to Telegram
:initial → :streaming → :tool → :streaming → :done

📊 Price Monitor

Фоновый сканер каждые 4 часа обходит 10 категорий на Lalafo.kg. Хранит снимки цен в SQLite, выявляет тренды и горящие deals.

;; Scanner pipeline
categories → search → items → snapshots → SQLite
→ trending / deals / history
